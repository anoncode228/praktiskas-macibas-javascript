# Par mani

Esmu Rīgas Tehniskās koledžas audzēknis un apgūstu programmēšanu. Mani interesē tīmekļa vietņu izstrāde, Linux, informācijas drošība un datoru tehnoloģijas.

Praktisko mācību laikā pilnveidoju savas prasmes HTML, CSS un JavaScript, veidojot interaktīvas un dažādām ierīcēm pielāgotas tīmekļa vietnes.
